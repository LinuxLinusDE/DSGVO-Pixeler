DSGVO-Pixeler Command Builder

Lokaler Konfigurator fuer den finalen CLI-Befehl. Alles laeuft im Browser, ohne Server.

Konfiguration

Die wichtigsten Einstellungen sind nach Themen gruppiert.

Ein- und Ausgabe

Dateipfade fuer Quelle und Ziel.

Pflichtfeld. Pfad zur Quelldatei, zu einem Ordner, zu einem Glob-Muster oder zu einer Komma-Liste von MP4-Dateien.
Optional. Wenn leer oder als Ordner gesetzt, erzeugt das Script selbst einen Dateinamen. Bei mehreren Inputs ist dies ein Zielordner.

Videoqualitaet

Preset, Codec und Snapshot-Verhalten.

Schneller Einstieg fuer Speed/Qualitaet. Default ist quality.
hevc ist effizient. h264 ist kompatibler.
Leer = Preset-Wert. Werte wie 50M sind moeglich.
Snapshot alle N Minuten (0 = aus).
Video aus Schwarz einblenden und nach Schwarz ausblenden (0 = aus).

Verpixelung

Anonymisierungsart und erkannte Zieltypen.

blur ist Standard. pixelate nutzt Blockgroessen.

Testoptionen und Debug

Kurze Testlaeufe und technische Debug-Overlays.

Optional. Nur die ersten N Minuten verarbeiten (0 = ganzes Video).
Erweitert

Feinabstimmung

Erkennungsparameter, Performance und technische Details.

Ultralytics Device, z.B. mps oder cpu.
Empfohlen 0.1-0.6. Leer = Preset-Default.
YOLO Inferenzgroesse. Hoeher = genauer, langsamer.
Detektionsbreite. 0 = Originalbreite.
Sicherheitsrand um erkannte Boxen in Pixeln.
Nur bei blur. Gerade Werte werden intern auf ungerade gesetzt.
Nur bei pixelate. Groesser = grober.
Nur bei pixelate. Groesser = grober.
Altes Feld. Besser blocks_plates und blocks_faces nutzen.
1 = aus, 2 = 2x2. Mehr hilft bei kleinen Objekten, kostet Zeit.
Statusausgabe alle N Frames mit aktuellen und durchschnittlichen FPS.
Statusausgabe spaetestens alle N Sekunden (0 = aus).
Format WIDTHxHEIGHT, z.B. 1920x1080.
Optionales Zielverzeichnis fuer Snapshots.

Modelle und Presets

Gewichte, Zusatzmodelle und gespeicherte Presets.

Speichert Parameter als Preset im Output-Ordner.
Preset JSON laden (Datei oder Basisname).
Kommagetrennte Liste fuer Kennzeichen-Modelle.
Kommagetrennte Liste fuer Gesichts-Modelle.
Optionale Zusatz-Modelle (kommagetrennt). Leer = aus.
Optional. Standard ist deaktiviert.

No-Pixel-Zonen (x1,y1,x2,y2)

Bild wird nur lokal im Browser verarbeitet, nichts wird hochgeladen.

Nutze ein Standbild mit derselben Aufloesung wie dein Video. Datei waehlen oder per Drag-and-Drop auf das Canvas ziehen.
Bild laden (oder auf das Feld ziehen) und Rechteck ziehen, um eine Zone zu setzen.
